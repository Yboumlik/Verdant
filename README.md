# Verdant | Nature's Essence

A responsive, minimal e-commerce website for high-end plant products. Designed with a focus on "Living Art" and sustainability.

## 🎨 Design System

### Color Palette
The design uses a curated selection of organic tones to reflect the brand's connection to nature.

| Color Name | Hex Code | Usage |
| :--- | :--- | :--- |
| **Deep Green** | `#2D4A3E` | Primary Brand Color, Headings, Footer |
| **Sage Green** | `#8B9D83` | Secondary Accents, Hovers, Highlights |
| **Earthy Gold** | `#D4A373` | Accent Details |
| **Off-White** | `#F9F7F2` | Backgrounds (Cream/Paper feel) |
| **Charcoal** | `#333333` | Body Text |
| **Pure White** | `#FFFFFF` | Cards, Text on Dark Backgrounds |

### Typography
- **Headings**: `Playfair Display` (Serif) - Adds a touch of elegance and premium feel.
- **Body**: `Outfit` (Sans-serif) - Clean, modern, and highly readable.

### Icons
- **Phosphor Icons** (CDN) - Minimalist line icons for a cohesive look.

## 🛠️ Setup & Usage

1.  Clone the repository or download the files.
2.  Ensure the `assets` folder contains the required images and video (`bloomscape-selfwatering-hero.mov`).
3.  Open `index.html` in any modern web browser.
4.  Navigate to `checkout.html` by clicking "Add to Cart" on any product.
